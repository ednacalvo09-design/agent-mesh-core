# Agent Mesh Core

O **Agent Mesh Core** é o framework central para orquestração de agentes autônomos, projetado para gerenciar fluxos de trabalho avançados, comunicação resiliente e arquiteturas modulares.

## 🚀 Visão Geral

Este repositório contém a infraestrutura principal (`core`) para coordenação de agentes, garantindo escalabilidade, segurança e alta performance na troca de mensagens e execução de tarefas distribuídas.

## 📁 Estrutura do Repositório

- **`docs/`**: Documentação técnica detalhada do framework.
- **`src/`**: Código-fonte principal da arquitetura de malha de agentes.
- **`tests/`**: Conjunto de testes automatizados para validação do sistema.
